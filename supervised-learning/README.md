# Supervised Learning Projects

This directory contains machine learning projects that use labeled data to train predictive models.  
Each project demonstrates a different supervised learning technique, including regression, classification, model evaluation, and feature engineering.

## Projects Included

### 🚗 Vehicle Price Prediction (Regression)
A full end‑to‑end project predicting used car prices using Linear Regression and Random Forest.  
Includes data cleaning, preprocessing, model comparison, and interpretation of results.

More supervised learning projects will be added over time.
